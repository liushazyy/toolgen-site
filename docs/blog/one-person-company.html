一人科技公司运营实录：工具链、成本与取舍

One-person tech company: toolchain, costs, and trade-offs

#一人公司 #创业 #AI Agent #成本

为什么做一人公司

传统软件公司 70% 的成本花在沟通与协调：会议、评审、需求转述、跨部门扯皮。 一人公司 + AI Agent 的结构把这些成本压缩到接近零——Agent 之间用结构化协议协作， 决策链路短，执行速度快。这不是「便宜版公司」，而是「另一种结构」。

团队架构：一个人 + 一群 Agent

  • 决策层（人）：定方向、做决策、验收结果。所有关键节点唯一的人类节点。
  • 执行层（Agent）：需求分析师、架构师、开发者、测试工程师、审查员——各司其职，并行协作。
  • 流水线（自动化）：CI/CD、自动测试、监控告警，质量关卡嵌入每个环节。

成本结构（真实数字）

  • 域名：toolgen.xyz 约 ¥50/年
  • 托管：GitHub Pages 免费（静态站）+ GitHub Actions 免费额度（公开仓库）
  • 模型 API：按量付费，一人公司用量可控
  • 本地服务器：阿里云 ECS 轻量实例（约 ¥100/月）

月固定成本可以压到 ¥200 以内。对比传统公司的人员工资+场地，成本结构完全不同。

哪些事自己做，哪些事外包

原则：AI Agent 能稳定复现的自己做，需要真人身份/资质的外包。

  • 自己做：开发、测试、审计、内容、运维、SEO——都是 Agent 能稳定交付的。
  • 外包/需要真人：注册资质、银行卡开户、需要人脸识别的实名认证、线下活动。

真实取舍

  • 速度 vs 质量：Agent 快但可能「自信地错」。所有交付必须过验证（测试/评审）才能对外。
  • 广度 vs 深度：一人公司接不了需要 10 人驻场的大单，专注小而深的垂直方向。
  • 自动化 vs 人工：能自动化的全自动化，把人的注意力留给决策。

给想试的人

  • 先把一个端到端流程跑通（接单→交付→收款），再谈扩张。
  • 每个 Agent 产出都要有验证环节——「不信任，只验证」。
  • 公开网站不放私人手机号，用邮箱做统一入口，隐私和安全都要想在前。
给 Agent 的任务书，要具体到「能写失败测试」才算合格；给维护者的 PR， 要具体到「红→绿证据链」才算专业。
