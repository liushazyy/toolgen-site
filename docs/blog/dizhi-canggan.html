地支藏干详解：每个地支里藏着哪些天干

Hidden stems of the twelve earthly branches, explained

#易学 #八字 #干支 #地支藏干

什么是地支藏干

天干有十个、地支有十二个，但地支并不是一个「单纯的五行符号」——每个地支内部 还暗藏着若干天干，称为「藏干」。比如子水之中藏着癸水，午火之中藏着丁火与己土。 地支藏干是八字（四柱）与奇门遁甲排盘的基础概念：天干代表「看得见」的表象， 地支藏干代表「藏得住」的内在力量。

十二地支藏干完整对照

子午卯酉四正位各藏一个本气干；寅申巳亥四生位、辰戌丑未四墓库各藏三个干。 完整对应关系如下：

  • 子（水）：藏 癸（本气）
  • 丑（土）：藏 己（本气）、癸（中气）、辛（余气）
  • 寅（木）：藏 甲（本气）、丙（中气）、戊（余气）
  • 卯（木）：藏 乙（本气）
  • 辰（土）：藏 戊（本气）、乙（中气）、癸（余气）
  • 巳（火）：藏 丙（本气）、戊（中气）、庚（余气）
  • 午（火）：藏 丁（本气）、己（中气）
  • 未（土）：藏 己（本气）、丁（中气）、乙（余气）
  • 申（金）：藏 庚（本气）、壬（中气）、戊（余气）
  • 酉（金）：藏 辛（本气）
  • 戌（土）：藏 戊（本气）、辛（中气）、丁（余气）
  • 亥（水）：藏 壬（本气）、甲（中气）

十二地支合计藏有 28 个天干（含重复），覆盖全部十个天干——地支是比表面 「丰富得多」的容器。这也是为什么看八字不能只看天干、还要看地支根气。

本气、中气、余气是什么意思

一个地支藏多个天干时，按力量大小分为三档：

  • 本气：与地支五行相同的天干，力量最强、占主导。如寅木的本气是甲木。
  • 中气：次要力量，多来自三合局或长生之气。如寅中藏丙火（火长生在寅）、亥中藏甲木（木长生在亥）。
  • 余气：最弱的一股气，一般是上一季节的残留。如寅中藏戊土（冬末春初的余土）。

力量排序：本气 > 中气 > 余气。命理分析中，本气决定地支的「主性格」， 中气与余气决定「隐藏的机会与暗藏的力量」。

记忆口诀

先按「四正 / 四生 / 四库」分组记框架：

  • 子午卯酉（四正）：只藏本气（午多一个己）——子癸、午丁己、卯乙、酉辛
  • 寅申巳亥（四生）：藏本气 + 长生中气 + 余气——寅甲丙戊、申庚壬戊、巳丙戊庚、亥壬甲
  • 辰戌丑未（四库）：藏本气土 + 入库之干 + 余气——辰戊乙癸、戌戊辛丁、丑己癸辛、未己丁乙

再配流传最广的顺口溜（一句一个地支，按子丑寅卯……顺序）：

  • 子藏癸水在其中，丑藏癸己辛金同
  • 寅藏甲木兼丙戊，卯中乙木独相逢
  • 辰藏乙戊三分癸，巳中庚金丙戊丛
  • 午藏丁火并己土，未中乙木加己丁
  • 申藏戊土庚行壬，酉中辛金独丰隆
  • 戌藏辛金及丁戊，亥中壬甲甲终存

藏干有什么用：透干与通根

八字分析中，藏干最核心的两个应用是「透干」和「通根」：

  • 透干：地支里藏的天干出现在四柱天干上，就叫「透出」。比如地支有寅、天干又有甲，甲木有根有源、力量大增；藏而不透则力量减半。
  • 通根：天干在地支藏干中找到同类，叫「有根」。甲木见寅（藏甲）是强根，见亥（藏甲）是弱根；天干在地支中找不到同类则「虚浮无根」，如水上浮萍。

判断一个十神旺不旺、能不能用，第一步永远是看它在四柱地支里有没有根。 这是从「会排盘」走向「会看盘」的关键一步。

常见误区

  • 午火不藏丙：午中只藏丁、己，不藏丙——午是丁火的禄地，不是丙的。
  • 四库土的藏干别记错：辰藏戊乙癸、戌藏戊辛丁、丑藏己癸辛、未藏己丁乙，四库各有专属的「入库之干」，这是墓库理论（入墓、开库）的基础。
  • 藏干不是十神：藏干本身只是天干，要按日主与它的生克关系转化成十神后才能参与分析（可参考本站《八字十神》一文）。

小结

地支藏干是打通「天干—地支」两层体系的关键：天干是明、地支是暗，天干看表象、 地支看根基。背熟十二地支藏干表与口诀之后，再看八字盘，每个地支就不再是孤立的 五行符号，而是一个「自带仓库」的完整系统——这也是进阶学习十神旺衰、格局取用、 以及奇门遁甲排盘（九宫藏干）的共同前提。

天干是明，地支是暗；看八字先看根，断吉凶先问库。
