梅花易数入门：起卦方法与体用生克断法

Meihua Yishu intro: casting methods and ti-yong sheng-ke

#梅花易数 #起卦 #体用生克 #周易 #易学

梅花易数是什么：邵雍与观梅占

梅花易数相传为北宋邵雍（邵康节）所创，名字来自他的经典案例「观梅占」： 某日邵雍观梅雀争枝坠地，随口起卦推知明日有女子折花伤股。与六爻、奇门不同， 梅花易数最大的特点是「随时随处可起卦」——不用铜钱、不摇卦， 时间、数字、声音、方位、外应皆可成卦。入门门槛低，特别适合初学者建立「卦感」， 也适合配合六十四卦基础一起学。

它断事的核心也不在复杂的六亲世应，而在体用生克： 一卦分体用，五行生克定吉凶，再辅以卦气旺衰与时令应期。规则少而清晰， 是易学入门最快、最能立刻上手的体系之一。

起卦第一步：时间起卦法

时间起卦是梅花易数最正统的起法，以农历年月日时为输入，分三步：

上卦：年月日之和除以八取余

  • 年数用地支序数：子1、丑2、寅3、卯4、辰5、巳6、午7、未8、申9、酉10、戌11、亥12。
  • 月、日直接用农历数字，例如农历八月十五日，月数取 8、日数取 15。
  • 三者相加 ÷8，余数对应先天八卦数取上卦；余 0 则视作 8（坤卦）。

下卦：再加时辰数除以八取余

时辰也用地支序数（子时1……亥时12，晚 23 点后算次日子时）。 年月日时四数总和 ÷8 取余得下卦。

动爻：四数总和除以六取余

总和 ÷6 取余即动爻（爻位自下而上数，余 0 则动第六爻）。 动爻是整卦的「机关」：它决定哪个卦为用卦，也决定变卦怎么变。

先天八卦数字对照（必须背熟）：乾1、兑2、离3、震4、巽5、坎6、艮7、坤8。

起卦第二步：数字与外应起卦

时间之外，最常见的起卦方式是「见数起卦」，规则更灵活：

  • 报数起卦：让求测人随口报两个数，第一个数 ÷8 取余得上卦，第二个数 ÷8 取余得下卦，两数之和 ÷6 取余得动爻。
  • 字数起卦：一句话分成前后两段，前段字数得上卦、后段字数得下卦，总字数取动爻；单字则按笔画数拆分。
  • 外应起卦：以当下所见之物成象——见三只鸟可取离（3），见七片落叶可取艮（7）；外应起卦重在「当下、自然、不刻意」，刻意取象反而失真。

一卦三身：本卦、互卦、变卦

起出的卦不是孤立的，梅花易数看的是「一卦三身」：

  • 本卦：起卦所得之卦，代表事情现状。
  • 互卦：本卦中间四爻重新组合——二三四爻为下互卦、三四五爻为上互卦，代表事情发展过程。
  • 变卦：动爻阴阳互换后得到的新卦，代表事情的结果与归宿。

断卦时三者串成一条时间线：本卦看当下，互卦看过程，变卦看结局。

断卦核心：体用生克

体用是梅花易数断吉凶的总纲，一句话即可定大方向：

  • 体卦：不含动爻的卦，代表求测人自己、主方、内因。
  • 用卦：含动爻的卦，代表所测之事、对方、外因。

体用关系只看五行生克，一共五种：

  • 用生体：事情主动来助力，最吉，得财得助。
  • 体克用：自己能掌控局面，但需主动出力，吉中有劳。
  • 比和：体用五行相同，平稳顺遂，诸事可成。
  • 体生用：自己付出供养对方，主耗损、泄气，不利。
  • 用克体：外势压制自己，主困难、破败，最凶。

生克力度还要看旺衰：体用得月令、日辰生扶为旺，吉凶力度加倍； 逢休囚死绝则打个折。例如体卦为土，占于辰戌丑未月（土旺）体旺， 占于亥子月（水旺土弱）体衰——同样的「用克体」，旺体扛得住，衰体一克就倒。 五行生克关系可对照五行入门一文复习。

断卦五步流程

  • 第一步定体用：找出动爻，动爻所在卦为用，另一卦为体。
  • 第二步辨旺衰：看体用两卦五行在月令、日辰的旺衰状态。
  • 第三步看生克：用五句生克口诀定吉凶大方向。
  • 第四步参互变：互卦看过程曲折，变卦看结局走向；变卦再与体卦比一次生克。
  • 第五步断应期：应期取卦气当令之时——用生体看用卦旺之日，体克用看体旺之日，也可参考动爻数（动三爻应三日、三月等），给区间再给节点。

案例：报数起卦断项目合作

某日求测人报数 3、7 问合作成败，起卦如下：

  • 上卦：3 ÷8 余 3，为离卦（火）；下卦：7 ÷8 余 7，为艮卦（山）；本卦为火山旅。
  • 动爻：(3+7)=10 ÷6 余 4，第四爻动，动爻在上卦，则用卦为离（火）、体卦为艮（土）。
  • 互卦：二三四爻为巽、三四五爻为兑，得泽风大过，主过程动荡、担子重。
  • 变卦：离卦初爻阳变阴，上卦变艮，得艮为山，主结果归于稳定。
  • 断：用生体（火生土），合作有外来助力，方向吉；但互卦大过提示过程周折、责任重；变卦比和，结局平稳落地。
  • 旺衰与应期：占于酉月金旺、火囚，生体之力偏弱，应期看火当令之日（巳、午日）见分晓。

常见误区

  • 起卦纠结时辰：现代生活以「当下心动那一刻」为准，过了就不算，比纠结子初子正更关键。
  • 体用定反：动爻所在为用、静卦为体，方向一错吉凶全反。
  • 生克不看旺衰：休囚之克与旺相之克力度天差地别，机械套口诀必误判。
  • 只看本卦：跳过互卦与变卦，等于只看了事情的起点，看不到过程和结局。
  • 忽略外应：断卦时当下突发的声响、物件移动都是外应，与外应相反的关键判断要再复核。

参考来源

《梅花易数》（旧题邵雍撰）、朱熹《周易本义》八卦取象、沈柏春《梅花易数预测学》 等现代著作的体用框架。本文为入门通用流程，体用分法与应期细则各流派略有差异， 入门后宜选定一派深入研习。

体用生克一句话定吉凶：用生体最吉，比和顺遂，用克体最凶； 再看互变定过程与结局——本卦看当下，互卦看过程，变卦看归宿。
