六爻纳甲装卦详解：纳甲、世应、六亲、六神一卦装齐

Liuyao Najia: dress the hexagram — stems, Shi-Ying, six relatives, six spirits

#六爻 #纳甲 #装卦 #六亲 #六神

背景

摇卦摇出来的是六个爻的阴阳组合（本卦）和动爻带来的变卦，但这时的卦还是「空壳」—— 每个爻既没有五行属性，也不知道它代表谁、管什么事。装卦，就是把干支、世应、六亲、六神 一层层装到卦上，让一卦从「阴阳符号」变成「可以断事的信息盘」。 本文按四步走：纳甲 → 定世应 → 装六亲 → 安六神。装完这四步，断卦需要的所有坐标就齐了。

装卦前：先分清内外卦与爻位

动手装卦前，先确认三个基本盘面信息：

  • 爻位：六爻从下往上数，依次是初爻、二爻、三爻、四爻、五爻、上爻。下三爻组成内卦（下卦），上三爻组成外卦（上卦）。
  • 本卦与变卦：动爻所在的爻，在变卦里对应一个新爻，那个爻有自己的地支——所以变爻要按变卦的爻重新纳支。
  • 八经卦五行：乾兑属金、离属火、震巽属木、坎属水、艮坤属土。这是后面定六亲的根。

第一步：纳甲——给每个爻配上干支

纳甲是给内外卦的六个爻配上地支。六爻断卦主要用地支的五行生克，天干只用在六神起法上， 所以重点记地支。八经卦纳支口诀如下（内卦三支 + 外卦三支）： 

乾：内 子寅辰   外 午申戌     震：内 子寅辰   外 午申戌
坎：内 寅辰午   外 申戌子     巽：内 丑亥酉   外 未巳卯
艮：内 辰午申   外 戌子寅     离：内 卯丑亥   外 酉未巳
坤：内 未巳卯   外 丑亥酉     兑：内 巳卯丑   外 亥酉未

口诀不用死背，记住规律就能推：

  • 阳卦顺行（乾坎艮震）：地支按子寅辰午申戌顺排；阴卦逆行（巽离坤兑）：地支按未巳卯丑亥酉逆排。
  • 内外分界：内卦从首支起排三支，外卦从第四支起排三支（阳卦午起、阴卦丑起）。
  • 天干只记纳甲：乾纳甲壬、坤纳乙癸、震纳庚、巽纳辛、坎纳戊、离纳己、艮纳丙、兑纳丁——卦名「纳甲」即由此来。

举例：天风姤卦是乾上巽下。外卦乾纳午申戌，内卦巽纳丑亥酉， 从初爻到上爻六个爻的地支就是丑、亥、酉、午、申、戌。 如果二爻动，变卦是天山遁（乾上艮下），二爻在变卦里属艮内卦，地支换成辰——这就是「变爻换支」。

第二步：定世应——立场与切入点

世爻代表求测人自己，应爻代表对方、所测之事的环境。断卦先看世应，再看用神落在哪一宫。 定世应靠八宫卦的排列顺序：每宫八卦从本宫卦开始，逐爻变化而来，世爻就落在「变了几个爻」的位置上：

  • 本宫卦（八纯卦）：世在六爻。例：乾为天。
  • 变一爻 → 一世卦：世在初爻。例：天风姤。
  • 变二爻 → 二世卦：世在二爻。例：天山遁。
  • 变三爻 → 三世卦：世在三爻。例：天地否。
  • 变四爻 → 四世卦：世在四爻。例：风地观。
  • 变五爻 → 五世卦：世在五爻。例：山地剥。
  • 五爻变后再回变四爻 → 游魂卦：世在四爻。例：火地晋。
  • 内卦三爻全部归回本宫 → 归魂卦：世在三爻。例：火天大有。

应爻永远和世爻隔两个爻位：世初应四、世二应五、世三应六、世四应初、世五应二。装完世应，卦的「立场」就定了。

第三步：装六亲——生克关系的坐标

六亲以卦宫五行为「我」来定：卦宫就是本宫卦的五行（乾兑宫金、离宫火、震巽宫木、坎宫水、艮坤宫土）。 每个爻的地支五行和「我」一比较，五种关系就出来了：

  • 生我者父母——长辈、文书、房屋、单位、保护伞。
  • 我生者子孙——子女、下属、财源、医药、福德。
  • 克我者官鬼——工作、官非、疾病、压力、丈夫（女测）。
  • 我克者妻财——钱财、妻子（男测）、货物、欲望对象。
  • 比和者兄弟——同辈、朋友、竞争者、破财因素。

例：乾宫卦属金。爻地支为土 → 土生金 → 父母；为水 → 金生水 → 子孙； 为火 → 火克金 → 官鬼；为木 → 金克木 → 妻财；为金 → 兄弟。 六亲装上后，断卦就有了用神体系：测事业找官鬼、测财运找妻财、测子女找子孙、测长辈找父母、测平辈找兄弟。

第四步：安六神——象意上的润色

六神按起卦当日的天干确定起点，从初爻到上爻依次顺排六位，口诀：

甲乙起青龙   丙丁起朱雀   戊日起勾陈
己日起腾蛇   庚辛起白虎   壬癸起玄武
  • 青龙：喜庆、文书、酒色、贵人。
  • 朱雀：口舌、信息、文书、争吵。
  • 勾陈：田土、拖延、牢狱、不动之物。
  • 腾蛇：虚惊、怪异、缠绕、梦寐不安。
  • 白虎：凶伤、疾病、血光、急迫。
  • 玄武：暗昧、盗贼、隐私、暧昧。

六神是修饰词：同样是官鬼，临白虎多主伤病之灾，临玄武多主暗中小人或失窃。 它是断卦的「着色层」，不能单独定吉凶，但在象意上往往一语道破关键。

装卦核对清单

  • 六个爻的地支是否按「内卦三支 + 外卦三支」纳全？变爻是否换成了变卦对应爻的地支？
  • 世应位置是否符合八宫卦顺序？游魂世四、归魂世三最容易装错，重点检查。
  • 六亲是否以卦宫五行为「我」展开，而不是拿日干、世爻五行去套？
  • 六神是否从起卦日天干起排、初爻到上爻顺序是否一致？
  • 装完后整体过一遍：卦宫五行、六个爻的生克关系能不能讲通？讲不通多半是某处装错了。

小结

装卦是六爻断卦的地基：纳甲定五行，世应定立场，六亲定人事，六神定象意。 四步装完，配合起卦与应期判断，一卦的信息盘就完整了。 装错了卦，后面断得再漂亮也是空中楼阁——每装完一卦，建议先过一遍上面的核对清单再动笔断事。

装卦四步缺一不可：纳甲定五行、世应定立场、六亲定人事、六神定象意。 卦装不齐，断卦无从谈起。
