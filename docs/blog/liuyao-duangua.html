六爻断卦入门：用神、原神、忌神与旺衰判断

Liuyao interpretation: yongshen, yuanshen, jishen and strength analysis

#六爻 #易学 #用神 #断卦

背景

n

六爻预测的完整流程是起卦、装卦、断卦三步。前两篇文章讲清了起卦和装卦，但很多初学者装完卦就卡住了：卦盘上密密麻麻的地支、六亲、世应都齐了，下一步该看什么？断卦不是「凭感觉说吉凶」，而是一套有固定顺序的推理过程。本文把断卦拆成四步：定用神、找原忌仇神、看旺衰、看动静生克，最后讲清楚空亡这个最常见的坑。照着这个顺序走，第一张卦就能断出有依据的结论。

nn

第一步：定用神——所测之事在卦里的代表

n

用神是断卦的起点，它是「所测之事」在六亲中的对应者。用神取错，后面全错。常用取用规则如下：

n
    n
  • 测财运、求财、生意利润：以妻财为用神；
    • n
  • 测官运、升职、官司、工作：以官鬼为用神（测工作也可兼看父母）；
    • n
  • 测父母、长辈、文书、学业、房产：以父母为用神；
    • n
  • 测子女、晚辈、下属、宠物：以子孙为用神；
    • n
  • 测兄弟、朋友、同辈、竞争：以兄弟为用神；
    • n
  • 测自己：以世爻为用神；测对方：以应爻为用神。
    • n
n

卦盘上每个六亲都有对应的地支爻位。找到用神爻之后，把它标记出来，后面所有分析都围绕它展开。用神在卦中不出现时（六亲不全），可以到伏神里找，这是进阶内容，新手先掌握「用神出现」的常规情况。

nn

第二步：找原神、忌神、仇神

n

围绕用神，其他爻分成三类关系：

n
    n
  • 原神：生用神的爻。原神旺相，用神有源头，事情有助力；
    • n
  • 忌神：克用神的爻。忌神发动或旺相，用神受伤，事情有阻力；
    • n
  • 仇神：生忌神、克原神的爻。仇神是「帮倒忙」的一方，它旺相会让忌神更凶、原神更弱。
    • n
n

举例：测财运，妻财为用神。妻财属木，则生木的水（父母）为原神，克木的金（兄弟）为忌神，生金的土（官鬼）为仇神。判断时重点看两个问题：原神能不能生到用神？忌神会不会来克用神？

nn

第三步：看旺衰——月建与日辰

n

旺衰决定爻的力量大小，是断卦的「权重」依据。主要看两处：

n
    n
  • 月建：起卦当月的地支。爻与月建同地支为「月建临之」最旺；受月建生扶为旺；被月建克为衰。
    • n
  • 日辰：起卦当天的地支。日辰对卦中所有爻都有生克权，爻得日辰生扶为旺，被日辰冲克为衰。
    • n
n

旺衰的量化经验：用神得月建、日辰生扶，或临月建，为「旺相」，事情根基扎实；用神被月建、日辰克泄，为「休囚」，事情力量不足。旺相的用神即使被忌神克，也未必凶；休囚的用神即使有原神生，也未必有力——先看力量，再看生克。

nn

第四步：看动静生克

n

卦中六爻分动静：动爻有权，静爻无权。判断生克时遵循两条铁律：

n
    n
  • 动爻可以生克静爻，静爻不能生克动爻（静爻只能被动接受）；
    • n
  • 动爻变出的变爻，只对本位动爻起作用，变爻回头生、回头克、回头冲，直接影响该动爻的力量。
    • n
n

综合判断的优先级：用神旺相 + 原神发动生用神 + 忌神安静或受制 = 吉；用神休囚 + 忌神发动克用神 + 原神安静或受制 = 凶。多数卦不用看得很复杂，抓住「用神有没有力量、有没有人帮、有没有人害」三点，结论就出来了。

nn

空亡：最常见的判断陷阱

n

空亡（旬空）是按起卦日的干支旬推算的：甲子旬中戌亥空，甲戌旬中申酉空，甲申旬中午未空，甲午旬中辰巳空，甲辰旬中寅卯空，甲寅旬中子丑空。用神临空亡，代表「暂时落空、事情还没落实」。

n
    n
  • 真空：用神休囚又逢空亡，事情难以落实；
    • n
  • 假空：用神旺相逢空亡，只是暂时受阻，出空（过了本旬）或填实（逢值之日）后应验；
    • n
  • 动爻逢空：动爻空亡力量打折，出空后发动才有效。
    • n
n

断空亡的要点是：先看旺衰再断空。旺相逢空是「暂时没到」，休囚逢空是「真的没有」，两者结论完全不同。

nn

新手断卦检查单

n
    n
  • 用神取对了吗？测的事对应哪个六亲？
    • n
  • 原神、忌神、仇神分别是谁？它们动不动？
    • n
  • 用神在月建、日辰下是旺还是衰？
    • n
  • 动爻里有没有忌神克用神、原神生用神？
    • n
  • 用神空亡没有？空亡是真还是假？
    • n
n

按这个顺序走完五步，再下结论。断卦的准确率不来自灵感，而来自流程的完整——每一步都做对，结论自然可靠。

断卦四步：先定用神，再分原忌，三看旺衰，四察动静。顺序不乱，吉凶自明。
